1. 階層構造とページのつながり（インデント構文）

行頭にスペースによるインデント（字下げ）を入れることで、要素同士の親子関係やコンテンツの繋がりを表現します。

記法 説明
インデント（スペース） 親要素の下にインデントを入れて記述することで、その親要素内に含まれる子コンテンツとしてレンダリングされます。
ツリー記号 (├─ / └─) 視覚的に繋がりをわかりやすくするためのツリー記号もインデントの一部（スペースと同等）として扱われます。
ネスト構造を表現する際、記号を含めたインデント量で親子の繋がりを判別します。

2. 全体レイアウト・構造枠

コンポーネント 記述パターン 説明
ヘッダー [ヘッダー: タイトル] 画面最上部に固定表示されるヘッダーバー
フッター [フッター: コピーライトなど] 画面最下部に固定表示されるフッターバー
メイン領域 [メイン領域] コンテンツ全体のベースとなる外枠エリア
ブロック枠 [ブロック名] コンテンツを囲む枠線エリア（内部要素に合わせて高さ自動調整）

3. フォーム＆UIコンポーネント

要素 記述パターン 備考・表示例
標準ボタン #btn: ボタン名# 灰色スタイルの標準ボタン
プライマリボタン #btn-primary: ボタン名# 青色アクセントの主要ボタン
テキスト入力枠 #input: プレースホルダー# テキスト入力用のインプットボックス
セレクトボックス #select: 選択肢1 | 選択肢2# パイプ記号（|）区切りでドロップダウン選択肢を指定
チェックボックス #check: ラベル名# 複数選択可能なチェックボックス
ラジオボタン #radio: ラベル名# 単一選択用のラジオボタン
通常テキスト $テキスト内容$ または $テキスト内容 標準的なラベル・本文テキスト
強調タイトルテキスト #タイトルテキスト# コロン指定のないコンポーネント。太字で強調表示されます
画像枠 img: 画像の説明
img: https://...		 説明テキスト付きプレースホルダー、またはWeb画像URLの直接描画
エスケープ処理 \$ \# \[ \] \| 記号自体を文字として表示したい場合は直前にバックスラッシュ（\）を付けます

4. 描画位置と横幅の指定

指定項目 記述パターン 説明
配置（アライメント） #input.center: 入力#
#btn.right: ボタン#		 コンポーネント名の後に .center / .left / .right を付与して、その要素の配置を指定します。
幅指定 (.w-1〜100) #input.w-30: 姓#
#btn-primary.w-50: 送信#		 コンポーネント名の直後に .w-数値 を付与し、親要素に対するパーセント幅を指定します。
色指定 (.red など) #btn.red: 削除#
#btn-primary.blue: 送信#		 コンポーネント名の後に .red / .blue / .green / .orange / .purple / .yellow / .pink / .cyan / .teal / .brown / .gray / .black / .white を付与して配色を指定します。

5. 多段レイアウト＆テーブル

機能 記述パターン 説明
カラム分割 [左エリア | 右エリア] パイプ記号 | で区切ることで左右多カラム構成を作成（エスケープ: \|）
簡易テーブル行 #tr: 項目名 (ステータス)# 表形式で描画。カッコ内のテキスト（編集可・閲覧のみ等）はハイライト表示化
要素の横並び $ラベル$ #input: 入力# #btn: ボタン# 1行の中に複数のテキストやコンポーネントを連続して書くことで、インラインで横並びに配置されます

6. 実戦コード例

インデント構造（├─ や └─）と記法（$, #, #tr:）を組み合わせることで、直感的にUI構造を定義できます。

[ヘッダー: ユーザー情報登録]

[メイン領域]
  [アカウント作成]
    ├─ #新規ユーザー情報の入力.center#
    ├─ #input.w-45: お名前# #input.w-45: フリガナ#
    ├─ #input.w-90: メールアドレス#
    ├─ #select.w-45: 権限を選択 | 一般ユーザー | 管理者#
    ├─ #check: 利用規約に同意する#
    └─ #btn.right.w-20: キャンセル# #btn-primary.right.w-30: 登録実行#

  [所属一覧]
    ├─ #tr: 部署名 (開発部)#
    └─ #tr: 役職 (リーダー)#

[フッター: © System Management]
