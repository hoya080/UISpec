# UISpec

UIワイヤーフレームをテキスト記法（DSL）で直感的に定義できるプレビューツールです。

インデントと専用記法を組み合わせて記述するだけで、ブラウザ上でUIのワイヤーフレームをリアルタイムにプレビューできます。

## 特徴

- **テキストベースのワイヤーフレーム定義** — 専用DSLでUI構造を記述
- **リアルタイムプレビュー** — エディタに入力すると即座に反映
- **マルチページ対応** — 複数画面をタブで管理可能
- **ツリー記号で視覚化** — `├─` / `└─` を使ったネスト構造の表現
- **書き出し機能** — テキスト / PNG画像 / HTMLの3形式でエクスポート

## ファイル構成

| ファイル | 説明 |
| --- | --- |
| `index.html` | メインのプレビューアプリ（エディタ＋プレビュー＋タブ管理） |
| `UISpec.html` | DSLの記法リファレンスガイド |

## 使い方

`index.html` をブラウザで開くだけで使用できます（サーバー不要・依存ライブラリはCDNから自動読込）。

1. 左側のエディタにDSLを入力
2. 右側にワイヤーフレームがリアルタイム表示される
3. `+` ボタンでページを追加、タブのダブルクリックでページ名を変更
4. ヘッダーのボタンからテキスト / PNG / HTML形式で保存

## 記法リファレンス

詳細は `UISpec.html` を参照してください。

### 基本構造

```text
[ヘッダー: タイトル]
[フッター: コピーライトなど]
[メイン領域]
[ブロック名]
```

### フォーム＆UIコンポーネント

```text
#btn: ボタン名#           標準ボタン
#btn-primary: 送信#       プライマリボタン（青）
#input: プレースホルダー#  テキスト入力枠
#select: A | B | C#       セレクトボックス
#check: ラベル#           チェックボックス
#radio: ラベル#           ラジオボタン
$テキスト内容$            通常テキスト
#タイトルテキスト#         強調テキスト（太字）
img: 画像の説明            画像枠（URL指定で実画像を表示）
```

### 属性（ドット区切りで指定）

```text
#input.center.w-40: 入力#     配置（.left / .center / .right）
#btn-primary.w-50: 送信#      幅（.w-1〜100、.w-auto）
#btn.red: 削除#               色（.red / .blue / .green / .orange / .purple / .yellow / .pink / .cyan / .teal / .brown / .gray / .black / .white）
```

### レイアウト

```text
[左エリア | 右エリア]        カラム分割（パイプで区切る）
#tr: 項目名 (状態)#          テーブル行
$ラベル$ #input: 入力#       同一行内での横並び配置
```

### エスケープ

記号そのものを表示したい場合は直前にバックスラッシュを付けます。

```text
\$ \# \[ \] \| \\ \( \)
```

### 実戦例

```text
[ヘッダー: ユーザー情報登録]

[メイン領域]
  [アカウント作成]
    ├─ #新規ユーザー情報の入力.center#
    ├─ #input.w-45: お名前# #input.w-45: フリガナ#
    ├─ #input.w-90: メールアドレス#
    ├─ #select.w-45: 権限を選択 | 一般ユーザー | 管理者#
    ├─ #check: 利用規約に同意する#
    └─ #btn.right.w-20: キャンセル# #btn-primary.right.w-30: 登録実行#

  [所属一覧]
    ├─ #tr: 部署名 (開発部)#
    └─ #tr: 役職 (リーダー)#

[フッター: © System Management]
```
